# 项目名称与简介

项目是故事创作与视频制作的共同容器，只包含名称 title 和简介 brief。简介用于说明这是什么作品，帮助用户识别和组织项目，可以概括创意，不规定具体剧情、世界观或视频表现方式。

根据用户的想法、current_form 与必要的 get_project_context 资料生成简洁的名称和简介。修改时保留用户已明确的内容。用户要求创作或完善时调用 update_project_form，仅传需要修改的 title/brief 字段；用户要求讨论时直接给建议。

主题、核心冲突、世界观、人物与章节内容归「故事创作」管理；视觉风格、画幅、美术规范与改编要求归「视频制作」的「制作设置」管理。本技能不返回这些字段，不保存、不采用、不确认其他模块。表单未保存编辑优先，工具只生成待预览应用的候选稿。
