# 配置指南

[返回文档索引](README.md)

所有启动、构建和迁移命令都应在项目根目录执行。应用读取进程环境变量，并加载 `.env.local` 和 `.env`；已存在的进程环境变量优先于环境文件，`.env.local` 优先于 `.env`。

## 推荐配置方式

启动后打开「模型管理」：

1. 在「服务连接」配置火山方舟、阿里云百炼或自定义兼容文本服务。
2. 点击「测试连接」，检查鉴权和模型目录查询结果。测试不会保存配置或生成内容。
3. 保存连接，然后在「模型选择」中分别选择图片、默认视频、文案和整体助手模型。

文案与助手可以使用不同模型；整体助手需要所选模型支持工具调用。图片和视频仅支持应用已适配的模型，不是任意兼容文本接口都能生成图片或视频。模型可见性与实际调用权限是两回事，以供应商账户权限和调用结果为准。

服务连接的 Key 留空会保留已保存密钥。运行模型任务期间，应用会阻止修改配置。数据库中的服务密钥使用 AES-256-GCM 加密，本机解密密钥位于工作区的 `.encryption-key`。

## 环境变量

参考仓库根目录的 [.env.example](../.env.example)，将需要的变量写入 `.env.local`。不要在版本库中保存真实凭据。修改环境变量后重启应用。

| 变量                | 用途与默认行为                                            |
| ------------------- | --------------------------------------------------------- |
| `PORT`              | HTTP 端口，默认 `3000`；监听地址固定为 `127.0.0.1`        |
| `DATA_DIR`          | 工作区目录，默认 `data/`，包含媒体、密钥和备份等          |
| `SQLITE_PATH`       | 数据库文件路径，默认是工作区中的 `frameflow.sqlite3`      |
| `FFMPEG_BIN`        | 自定义 FFmpeg 可执行文件；未设置时使用 npm 依赖提供的版本 |
| `ARK_API_KEY`       | 火山方舟 API Key                                          |
| `ARK_TEXT_MODEL`    | 方舟文本模型的环境默认值                                  |
| `ARK_IMAGE_MODEL`   | 图片模型的环境默认值                                      |
| `ARK_AUDIO_MODEL`   | 字幕所用音频模型的环境配置                                |
| `DASHSCOPE_API_KEY` | 阿里云百炼 API Key                                        |
| `WAN_REGION`        | 百炼地域，支持 `beijing` 和 `singapore`，默认 `beijing`   |
| `LLM_BASE_URL`      | 自定义兼容文本服务地址                                    |
| `LLM_API_KEY`       | 自定义兼容文本服务 API Key                                |
| `LLM_MODEL`         | 自定义文本服务的模型默认值                                |
| `DATABASE_URL`      | 仅供旧版 PostgreSQL 导入工具读取，正常运行不需要          |

已在模型管理中保存的配置优先于对应环境默认值。文案和助手的角色选择会影响实际使用的服务与模型；更改环境默认值不会覆盖已保存的选择。模型 ID 默认值以 [.env.example](../.env.example) 和当前实现为准，使用前应确认自己的账号拥有权限。

自定义文本地址需要完整的 HTTP 或 HTTPS URL，不应包含账号、密钥、查询参数或 URL 片段。百炼业务空间 ID 在模型管理中填写，不是上述环境变量之一。

## 改端口或数据位置

例如在 `.env.local` 中设置：

```dotenv
PORT=3001
DATA_DIR=/absolute/path/to/daydream-data
# SQLITE_PATH=/absolute/path/to/daydream-data/frameflow.sqlite3
# FFMPEG_BIN=/absolute/path/to/ffmpeg
```

改端口后访问 `http://127.0.0.1:3001`。

`DATA_DIR` 和 `SQLITE_PATH` 的相对路径均以启动时的工作目录为基准。只设置 `SQLITE_PATH` 不会移动媒体、密钥和备份。更改数据位置之前，请先按[备份与恢复指南](data-management.md)保存并迁移已有工作区；直接指向空目录会创建一个新工作区。

## 外部服务与本机运行

项目和媒体保存在本机。执行 AI 请求时，相关提示词、参考素材或音频会发送给配置的模型服务，实际费用、配额和数据处理方式取决于该服务。

当前没有账户系统、多人隔离或面向公网的部署流程。生产模式仍是本机单用户运行方式，使用 `npm run build` 后执行 `npm start`。
