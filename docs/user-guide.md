## 项目与模型

首页无需登录即可访问。右上角点击「登录」，在弹窗内输入手机号和密码；新手机号会提示填写用户名称并再次确认密码，两次一致后提交加入申请；管理员审核通过后才能登录。已有且审核通过的账号验证密码后直接登录。登录后进入「我的项目」工作台，用于创建或打开项目，只需填写名称和简介。所有页面保留全局顶栏：点击 Daydream 返回首页，点击右上角头像进入「我的项目」，头像旁的下拉菜单提供「账户设置」、「模型配置」和「退出登录」。进入项目后，侧栏提供视频制作、故事创作、素材库和任务记录，顶部项目名称可展开切换其他项目。每个项目拥有一部故事和多个视频分集。「模型管理」分成两个模块：

- 「模型选择」分别配置图片生成、默认视频、文字和功能（流程）。文字与功能（流程）可以使用不同模型及服务；视频默认值用于新建分集和制作方案，已有方案保留原模型，可在分集的生成设置中切换。
- 「服务连接」统一配置火山方舟、阿里云百炼与自定义兼容文本服务的 Key、地址或地域，各服务单独保存。Key 留空保留原密钥；文字与功能（流程）复用所选服务的连接。

模型下拉框从已保存的服务连接拉取目录，按图片生成、视频生成和文本生成能力分类，支持按名称或 ID 搜索及手动刷新；目录缓存五分钟，连接配置改变后会重新拉取。目录刷新不改变原有选择。可见模型不等于已开通调用权限，列表分别显示「已授权」或「权限待确认」；已适配模型排在前面；应用暂未适配的图片、视频模型保留在列表后方并置灰。文字和功能（流程）可在火山方舟、阿里云百炼和自定义兼容服务之间选择；自定义接入点或目录缺少能力信息时，可切换到手动输入模型 ID。

图片生成支持方舟 Seedream 5.0 Pro / Flash，以及百炼 Qwen Image 2.0（含日期版本）、2.1 Pro / Turbo、3.0 / Pro。选择 Qwen 后自动使用百炼连接的 Key、地域和业务空间，支持文生图和参考图生成；结果保存为本地 PNG，可继续作为后续视图的参考。

百炼的模型目录会读取全部分页。服务连接中可填写业务空间 ID，填入后使用对应地域的专属域名；北京地域还会尝试查询已授权模型，授权接口不可用时保留目录并提示权限待确认。方舟使用 API Key 查询可见目录，暂不配置额外的 Access Key 来核验模型开通状态。

「测试连接」使用当前输入的 Key，留空时使用已保存的密钥，只查询模型列表，不保存配置或生成内容。结果显示连接与鉴权是否成功、耗时和返回模型数量，具体模型权限仍以实际调用为准。自定义文本服务需要支持 Chat Completions 的 JSON 输出；不支持模型列表接口时，连接测试会明确提示。

## 分集制作

分集左侧按故事、分镜与资源、视频生成、合成导出、结束方案展示进度。集名旁的编辑按钮可修改本集名称和剧情，旁边的加号用于新建方案。当前阶段、生成任务和上游变更状态直接标在对应阶段。视频进度只统计已采用且仍有效的正式片段。

导出有效成片且没有排队或运行中的任务后，可进入「结束方案」手动确认锁定。已结束方案只能查看和下载，不能再编辑、采用版本、生成内容或向助手提交创作请求。仍可切换方案，或新建方案继续编辑；从已结束方案新建时默认复制全部内容，新方案不继承锁定状态，修改不会影响原方案。

每集只能有一个已结束方案。结束另一方案时，原方案的最后一个「结束方案」节点退回未结束，已有内容和成片保留。只要存在已结束方案，概览的状态、封面、预览和默认查看入口都以该方案为准；新方案只显示「有新版本」提示，直到它被结束后替换展示。

1. 在分集总览创建分集，进入制作方案。
2. 先在项目的「故事创作」中完成并定稿章节，再在本集「故事」环节勾选一章或多章，点击「选定章节并继续」。
3. 在「分镜与资源」先从故事展开分镜，再分析与匹配素材。两个动作可分别配置模型，生成结果直接进入可编辑草稿并支持撤销，保存后写入新版本。底部时间轴固定在工作区，不随内容滚动；它只展示镜头编号与时长，用作镜头切换。顶部直接提供「生成分镜」和「匹配素材」。选中镜头后，在占满编辑区的唯一描述框里编写画面、动作、景别机位运镜、台词旁白与声音，输入 @ 引用资源。镜头标题旁的「优化此镜头」使用分镜模型，只优化当前描述，保持时间、资源标签及其他镜头不变。AI 结果直接写入草稿，工具栏可撤销，无需处理额外结果卡片。时长通过拖动镜头右边缘调整，前插、后插和删除也都在底部时间轴完成，后续镜头自动重新排时。无需勾选资源核对项。分镜描述中的资源以行内标签显示；悬停预览，点击可切换资源、版本和参考视图，也可新建素材或生成参考图。
4. 核对每镜素材后确认，进入视频生成。系统根据视频模型的时长与参考资源限制自动组合片段，优先减少调用；8 秒分镜在模型允许时组合成一条请求。手动选择的素材在重新匹配时保留。
5. 逐段生成视频，或先预览整集复用数量和新增时长，再确认生成。生成结果保留为候选，需要明确采用；样片不能直接用于成片。
6. 合成导出选择分辨率、字幕方式、片段顺序和裁切。原有成片和历史导出都可预览下载。

分镜的单个单元称为「镜头」，表示一次连续拍摄；后续视频模型的一次生成结果称为「片段」，可包含多个镜头。生成和优化使用同一套写作规范：交代开始画面、关键动作、摄影方式、台词声音和结束状态，每镜承担一个叙事重点；动作量与时长相符，相邻镜头保持位置、视线、道具和动作阶段连续，固定外观不在每镜反复抄写。规范文件为 `skills/creation/storyboard/SKILL.md`。最终视频请求只包含一份镜头时间表，明确标注镜头边界，项目规范与资源信息分别集中提供。

一个分集可创建多个制作方案，选择继承当前选章、复制全部内容与采用结果，或从空白开始。切换方案不会删除历史版本。

## 统一创作助手

全书方案、故事与章节创作、连续写作、全书检查、分镜生成、素材匹配、镜头优化、生图、视频生成和导出都使用右下角的「创作助手」。文字候选稿在浮窗中预览后应用；制作任务展示参数与计费说明，点击执行后提交，进度也在浮窗显示。「创作助手」支持新对话和已有制作方案的历史对话。切换模块时可继续当前会话；收起助手不影响编辑。

从模块点击「AI 生成」或「与助手讨论」会新建独立会话，预填可编辑的任务请求和 skill 标签，不继承其他会话的历史消息。助手会按需读取当前未保存表单、项目规范、分集和相关资源；不用先手动汇总已有资料。输入 `@` 可以明确指定技能、环节或资源，未指定技能时助手也可按任务自动加载。只有明确要求先讨论、不生成时才仅给建议。

新会话的生成结果以卡片预览。点击「应用」才回填原表单，检查后仍需保存或确认。如果等待期间修改了表单、关闭了原表单，或结果技能不匹配，旧结果不能应用到新内容上。

已有的跨阶段历史对话保留对应分集和制作方案的持久化记录，可以结合该方案上下文讨论。明确要求修改时，助手可保存待审阅版本；仍需手动采用与确认。未确认前置阶段时可以讨论，生成后续阶段草稿仍需满足相应条件。助手不会通过对话直接启动设定图、视频或导出任务。

## 版本与恢复

故事按作品修订保存，各章节区分草稿与定稿；视频保存选章来源快照，其余制作环节分别记录草稿、采用版本和阶段确认状态。上游更改后，下游显示待更新；历史文件保留，不会自动替换新结果。编辑时的定时刷新不会覆盖未保存内容，应用内离开或切换版本会提示未保存修改。

任务记录查看进度、失败原因和下载结果。带远端 ID 的失败视频可继续查询，不会重新创建计费任务；整集任务可继续未完成部分。若提交结果不确定且没有远端 ID，请先在供应商控制台核对，不要直接重复生成。

字幕可以不添加、识别实际语音，或将导演方案中的台词对齐实际音频。自动字幕会调用配置的音频模型；对齐无法完整保留台词时任务失败，原成片仍保留。

### 用创作助手完成当前模块

项目内先在「故事创作」中完成并定稿章节，再在「视频制作」中创建分集、选择章节、编排分镜与资源、生成审阅视频和合成导出。新建项目可以先写一句创意，点击「AI 生成」，由助手完善名称和简介；视频表现方式通过「制作设置」单独配置。

各创作模块提供「AI 生成」和「与助手讨论」入口，打开独立会话并预填请求。助手会自行读取相关资料并交付第一版卡片；资料为空时采用合理的创作假设并说明，可在同一会话继续提出修改意见。检查卡片后点击「应用」，再保存表单。也可在会话选择中继续已有分集的跨阶段历史对话。

文字内容创作使用「文字」模型，助手调度与素材匹配使用「功能（流程）」模型；通过工具交付结果的模型需要支持工具调用。生成和讨论会调用供应商；素材生成、结果采用和导出仍通过各自入口执行。完整的模块、skill 和 tool 对应关系见 [创作流程与助手协作](creation-workflow.md)。

### 素材库分类与出图

素材库以缩略图网格展示，可按人物、场景、道具筛选，并显示各类数量。搜索支持名称、全部状态的描述、剧情状态名称和标签，忽略首尾空格与英文字母大小写；多个关键词需同时匹配。点击卡片打开详情面板，小屏幕下进入独立详情并可返回列表。在分类中新增资源会预选对应类型。填写设定描述后，点击「生成设定图」即可直接出图，无需创建分集或制作方案，使用模型管理中配置的生图模型。

人物每次生成一张四视图设定板，2×2 排列正面全身、侧面全身、背面全身及正面半身特写，统一同一角色的造型、服装与材质；场景只生成一张空间全景图；道具保持一张完整三分之四视角设定图。每项素材每次只请求一张图片。角色设定板作为一张参考图传入支持参考图的视频模型，并明确用于造型一致性，不复刻四区布局。生成期间卡片显示任务状态，完成后图片保存为候选，不自动替换当前采用图，也不更新分镜。任务记录可查看生成结果。详情中可预览、放大、对比当前图，再明确采用候选或继续保留历史版本。填写的本次出图调整要求只影响该次请求，不会修改素材设定；PNG、JPEG 图片可上传（最大20MB），预览确认后同样保存为候选。

详情的「设定」保存当前状态的新文字版本，原采用图仍保留；依据旧设定生成的图片会明确提示。「新增状态」继承当前造型作为参考，可创建穿雨衣、受损等独立状态；每个状态分别保存设定和采用图。切换素材、状态或离开页面前会提示未保存的修改。

「使用位置」列出引用该状态的分集、方案和镜头。采用新图不自动改变已有绑定；按方案选择更新范围并确认后，所选方案创建新的资源草稿，需重新确认并检查受影响视频。已结束、永久锁定或正在生成的方案不能更新，历史版本与其他方案保留。分镜资源弹窗可直接前往素材库审阅候选。

### 视频制作

打开、新建或切换项目后，默认进入「视频制作」。顶部直接展示项目名称和简介，点击旁边的「编辑项目」修改。这里仅管理作品标识与说明，修改名称或简介不会让故事、分镜或已生成素材待更新。

视频制作标题旁提供「制作设置」，集中配置视觉风格、画幅、美术规范与改编要求。美术规范决定画面质感、配色、光线、服装与场景的视觉表达；改编要求决定原文如何拍成视频，例如叙事视角、节奏、旁白与情节保留。故事主题、世界规则和人物关系在「故事创作」中管理。

「AI 完善项目简介」只生成名称与简介卡片；「AI 完善制作设置」只生成视频设置卡片，应用后仍需保存。制作设置供分镜、设定图、视频生成与合成导出读取。修改制作设置会让进行中的视频方案待复核，故事正文和已选原文不变；已结束方案保留原结果。保存使用制作设置独立的修订号，避免并发覆盖。

下方以卡片展示全部分集，按集数倒序排列，首张卡片为「制作新一集」。已有成片的卡片使用真实视频第一帧作为封面，可直接播放；卡片同时显示当前制作状态和「继续制作／查看制作」入口。优先播放当前方案的有效成片；当前方案尚未出片时，仍展示该集其他方案最近完成的有效成片。过期成片不会作为当前结果列出。侧栏依次为视频制作、故事创作、素材库和任务记录。从分集卡片的「继续制作／查看制作」进入该集工作台，工作台顶部显示项目与分集名称，并可直接返回视频制作。

修改制作设置会让进行中的视频方案待更新，原内容和媒体保留；已结束方案保留原有结果。配置有新的并发更新时，保存会提示重新载入，避免覆盖新数据。

### 故事创作与视频选章

在项目侧栏的「视频制作」下方打开「故事创作」。每个项目维护一部长篇小说，默认目标30万字、每章3000字。首次进入时会带入项目简介作为想法。输入或修改想法，选择目标篇幅和每章长度，点击「帮我生成全书方案」进入全局浮窗，发送要求、审阅候选稿并应用后保存方案；没有想法可以选择示例或留空，由系统构思。

1. **全书方案**：系统生成故事核心、题材、主题、世界、人物、全书主线、结局和连续覆盖全书的分卷计划。每卷包含目标、高潮和阶段结局；结局默认折叠，避免提前剧透。
2. **开始写作**：检查方案后点击「试写第一章」。系统只细化接下来至多五章，再展开当前章正文；可选择写下一章、连续写5章或一直写到全书结局。
3. **持续保存**：近期章节计划、正文和累计剧情记忆逐步保存。关闭页面不影响后台任务；点击暂停后，当前未完成步骤不写入，已有章节保留。失败可从保存处继续。服务重启后任务暂停，需手动继续。
4. **阅读与修改**：目录显示已规划、初稿和已定稿章节。打开「修改本章」可编辑标题、提要与正文，也可以让助手改写当前章。开始新任务前自动保存修改；自动写作期间请先暂停再编辑。
5. **剧情记忆**：每章记录实际事件、人物状态与知识边界、待回收线索和时间位置。修改前文或全书设定后，受影响的后续记忆作废；继续写作先重建记忆，已有正文不自动改写。发现一致性问题时暂停，并列出需要修改的内容。
6. **全书检查与完结**：全部章节完成、记忆有效且字数达到目标的85%以上后，可运行全书检查。系统先逐卷检查，再汇总主线、人物成长与伏笔收束；检查基于实际章节摘要与剧情记忆，并非逐字校对。处理报告中的问题后重新检查，由用户审阅并确认完结。顶部可导出整部小说正文为 TXT。

「手动编辑设定与全书方案」保留构思、人物、世界、大纲、分卷和结局的编辑入口。助手候选稿应用后仍需保存。正文、提要或标题修改后章节回到草稿；点击「定稿本章」才能被视频选用。小说完结与视频选章定稿是独立操作。小说不受视频模型、画幅或分集时长限制。

进入视频分集的「故事」环节，勾选本项目的一章或多章已定稿章节，预览正文，点击「选定章节并继续」。章节按原文顺序组合，视频分集不必和章节一一对应。这里不再提供正文生成或手写编辑。

视频保存选用时的作品修订、章节原文和世界人物设定快照。原文后续修改或移除章节不会覆盖已有视频依据；重新进入选章时会提示作品版本更新，明确重新选定才会使下游依据变化。同一故事可供本项目的多个视频分集与制作方案使用。

### 剧情状态与修订版本

「分镜与资源」中的资源标签是本集绑定入口。点击标签可选择素材库的具体版本与参考视图，修改当前镜头或同步其他引用。修改外观描述会创建新版本，旧图片作为参考保留，新版本需重新生成图片。不同镜头可选择同一素材的不同状态。

修正描述和重新出图属于同一状态的版本迭代；新增状态则保留独立的状态身份、来源版本、标签与图片。素材库中可以按状态查看历史版本，从素材库绑定时明确选择状态和版本。历史制作方案不会自动替换为最新版本。旧资源自动归入「初始状态」，无需迁移。

### 制作模块的统一标题工具栏

故事、分镜与资源、视频生成、合成导出与结束方案统一使用固定的标题行：模块名称后显示版本与当前状态，右侧放生成、保存、确认、导出等主操作。次要操作位于右侧「更多操作」，正文只负责内容编辑和预览。单个镜头、片段或设定条目的局部操作仍放在条目旁。切换阶段后工具栏随模块更新，已结束方案的编辑操作保持禁用。

### 查看生成时使用的 skill 与提示词

从模块点击「AI 生成」时，预置请求带有对应 skill 标签，例如 `@skill:director`。显式标签优先加载；没有标签时，助手可以自行加载匹配技能。当前表单和项目定位作为可按需读取的资料来源，助手通过工具查询，不直接拼进初始消息。环节与资源引用用于强调参考目标，不是读取资料的前置条件。

回复下的「本次 skill 与提示词」可展开查看本次实际发送的请求，包括 skill 文件来源、系统消息、上下文、对话和工具定义。请求预览不包含服务连接认证信息。自由聊天也可显式引用 skill；能否将结果应用到原表单，取决于技能匹配和表单快照是否仍有效。

## 邀请申请与管理后台

当前处于邀请制内测。首次填写手机号和密码后，在同一弹窗补充用户名称、再次确认密码后提交加入申请。申请提交后会提示「申请审核中」，不进入工作台。审核通过后，使用原手机号和密码登录；申请被拒绝或账号被停用时，弹窗会明确提示状态。

管理员登录后，从头像旁的下拉菜单进入「管理后台」，菜单中显示待审核数量。管理后台支持按名称、手机号搜索，以及按待审核、已通过、已拒绝、已停用筛选。在申请行点击「通过」或「拒绝」并确认即可完成审核。账号停用会立即使其登录会话失效，项目和配置保留；恢复后需重新登录。列表每 15 秒自动更新，可手动刷新。当前不发送短信或邮件通知。

## 账户设置

从头像旁的下拉菜单进入「账户设置」。账户名支持 2–20 个字符，保存后同步更新头像菜单；手机号完整展示且不可修改，头像继续根据该手机号生成。修改密码需要输入原密码、新密码及确认新密码，新密码至少 8 位。修改成功后退出所有设备，并返回首页登录弹窗，使用新密码重新登录。

管理员账号由服务器运行 `npm run admin:create -- <手机号>` 添加。新账号在终端设置名称和密码；已有账号确认后授予管理员权限，保留原密码和数据。完成后通过普通登录弹窗登录，无需打开初始化链接。

## 首次管理员设置与管理员授权

第一次启动且没有管理员时，首页进入「首次初始化管理员」。打开服务器启动日志提供的一次性初始化链接，填写手机号、账户名、密码和确认密码，完成后直接进入管理后台。若该手机号已有普通账号，需要填写原密码。口令过期可重启服务器生成新链接；已有管理员后，该入口关闭。

管理员在后台的「已通过」列表中，可点击普通用户旁的「设为管理员」，核对名称和手机号并确认。该用户原名称、密码和数据保留，重新登录后获得管理员权限。该操作会记录由哪位管理员授权。服务器的 `admin:create` 命令仍可用于添加或激活管理员账号。

模型设置仅分为图片、视频、文字、功能（流程）四类。故事、分镜与文案完善统一使用文字模型；助手调度和素材匹配统一使用功能（流程）模型。各创作环节不再单独配置模型，使用工具交付结果的文字模型也需要支持工具调用。
