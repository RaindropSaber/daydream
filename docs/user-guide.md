# 使用说明

## 项目与模型

「我的项目」采用无侧栏的项目列表页，用于创建或打开项目，设置创作方向、风格和画幅。进入项目后，侧栏切换为该项目的工作台导航，提供分集总览、共享资源和任务记录；侧栏顶部的项目名称可展开切换其他项目，侧栏底部的「我的项目」可打开项目列表，位于「模型管理」上方。模型管理固定在工作台侧栏底部，项目列表页则在顶栏提供入口；在项目内进入时保留项目上下文。「模型管理」分成两个模块：

- 「模型选择」分别配置图片生成、默认视频、文案创作和整体助手 Agent。文案与助手可以使用不同模型及服务；视频默认值用于新建分集和制作方案，已有方案保留原模型，可在分集的生成设置中切换。
- 「服务连接」统一配置火山方舟、阿里云百炼与自定义兼容文本服务的 Key、地址或地域，各服务单独保存。Key 留空保留原密钥；文案与助手复用所选服务的连接。

模型下拉框从已保存的服务连接拉取目录，按图片生成、视频生成和文本生成能力分类，支持按名称或 ID 搜索及手动刷新；目录缓存五分钟，连接配置改变后会重新拉取。目录刷新不改变原有选择。可见模型不等于已开通调用权限，列表分别显示「已授权」或「权限待确认」；已适配模型排在前面；应用暂未适配的图片、视频模型保留在列表后方并置灰。文案和助手可在火山方舟、阿里云百炼和自定义兼容服务之间选择；自定义接入点或目录缺少能力信息时，可切换到手动输入模型 ID。

图片生成支持方舟 Seedream 5.0 Pro / Flash，以及百炼 Qwen Image 2.0（含日期版本）、2.1 Pro / Turbo、3.0 / Pro。选择 Qwen 后自动使用百炼连接的 Key、地域和业务空间，支持文生图和参考图生成；结果保存为本地 PNG，可继续作为后续视图的参考。

百炼的模型目录会读取全部分页。服务连接中可填写业务空间 ID，填入后使用对应地域的专属域名；北京地域还会尝试查询已授权模型，授权接口不可用时保留目录并提示权限待确认。方舟使用 API Key 查询可见目录，暂不配置额外的 Access Key 来核验模型开通状态。

「测试连接」使用当前输入的 Key，留空时使用已保存的密钥，只查询模型列表，不保存配置或生成内容。结果显示连接与鉴权是否成功、耗时和返回模型数量，具体模型权限仍以实际调用为准。自定义文本服务需要支持 Chat Completions 的 JSON 输出；不支持模型列表接口时，连接测试会明确提示。

## 分集制作

分集左侧的竖向「制作流水线」按故事、视频方案、设定集、视频生成、合成导出、结束方案显示阶段产出与完成步数。分集名称、制作方案切换和新建方案入口合并在左侧流水线顶部，不再单独占用顶部横栏。模块标题和左侧流水线保持固定，右侧当前模块内容独立滚动。当前查看的阶段单独高亮；生成中、排队、任务失败和上游变更后的「需更新」会直接标在对应阶段。点击阶段可切换对应工作区，成片预览和下载在「合成导出」中操作。视频进度只统计已采用且仍有效的正式片段，未采用候选与样片不计入完成数。

导出有效成片且没有排队或运行中的任务后，可进入「结束方案」手动确认锁定。已结束方案只能查看和下载，不能再编辑、采用版本、生成内容或向助手提交创作请求。仍可切换方案，或新建方案继续编辑；从已结束方案新建时默认复制全部内容，新方案不继承锁定状态，修改不会影响原方案。

每集只能有一个已结束方案。结束另一方案时，原方案的最后一个「结束方案」节点退回未结束，已有内容和成片保留。只要存在已结束方案，概览的状态、封面、预览和默认查看入口都以该方案为准；新方案只显示「有新版本」提示，直到它被结束后替换展示。

1. 在分集总览创建分集，进入制作方案。
2. 编写故事，或通过创作对话讨论并整理完整草稿。检查后点击「确认并继续」，保存并确认当前故事，进入下一阶段。
3. 视频方案包含统一导演意图、连续时间节拍及生成片段。可编辑时间、对白、提示词、续写关系和资源具体版本；聚合片段会另存为候选稿。
4. 整理设定集，审阅世界观、人物、场景和道具。可复用项目资源版本或生成设定图。确认完整设定后进入视频生成。
5. 逐段生成视频，或先预览整集复用数量和新增时长，再确认生成。生成结果保留为候选，需要明确采用；样片不能直接用于成片。
6. 合成导出选择分辨率、字幕方式、片段顺序和裁切。原有成片和历史导出都可预览下载。

一个分集可创建多个制作方案，选择继承故事、复制全部内容与采用结果，或从空白开始。切换方案不会删除历史版本。

## 统一创作助手

右下角的「创作助手」支持新对话和已有制作方案的历史对话。切换模块时可继续当前会话；收起助手不影响编辑。

从模块点击「AI 生成」或「与助手讨论」会新建独立会话，预填可编辑的任务请求和 skill 标签，不继承其他会话的历史消息。助手会按需读取当前未保存表单、项目规范、分集和相关资源；不用先手动汇总已有资料。输入 `@` 可以明确指定技能、环节或资源，未指定技能时助手也可按任务自动加载。只有明确要求先讨论、不生成时才仅给建议。

新会话的生成结果以卡片预览。点击「应用」才回填原表单，检查后仍需保存或确认。如果等待期间修改了表单、关闭了原表单，或结果技能不匹配，旧结果不能应用到新内容上。

已有的跨阶段历史对话保留对应分集和制作方案的持久化记录，可以结合该方案上下文讨论。明确要求修改时，助手可保存待审阅版本；仍需手动采用与确认。未确认前置阶段时可以讨论，生成后续阶段草稿仍需满足相应条件。助手不会通过对话直接启动设定图、视频或导出任务。

## 版本与恢复

系统分别记录草稿、采用版本和阶段确认状态；故事编辑区的「确认并继续」会一并保存并确认当前稿，不需要额外点击采用。上游更改后，下游显示待更新；历史文件保留，不会自动替换新结果。编辑时的定时刷新不会覆盖未保存内容，应用内离开或切换版本会提示未保存修改。

任务记录查看进度、失败原因和下载结果。带远端 ID 的失败视频可继续查询，不会重新创建计费任务；整集任务可继续未完成部分。若提交结果不确定且没有远端 ID，请先在供应商控制台核对，不要直接重复生成。

字幕可以不添加、识别实际语音，或将导演方案中的台词对齐实际音频。自动字幕会调用配置的音频模型；对齐无法完整保留台词时任务失败，原成片仍保留。

### 用创作助手完成当前模块

正常流程为项目构思、分集大纲、故事、分镜与片段、设定集、生成审阅和合成导出。新建项目可以先写一句创意，点击「AI 生成」，由助手完善名称、方向与一份统一创作规范，不需要逐项填写美术维度。

各创作模块提供「AI 生成」和「与助手讨论」入口，打开独立会话并预填请求。助手会自行读取相关资料并交付第一版卡片；资料为空时采用合理的创作假设并说明，可在同一会话继续提出修改意见。检查卡片后点击「应用」，再保存表单。也可在会话选择中继续已有分集的跨阶段历史对话。

AI 使用模型管理中的「整体助手」模型，需要该模型支持工具调用。生成和讨论会调用供应商；素材生成、结果采用和导出仍通过各自入口执行。完整的模块、skill 和 tool 对应关系见 [创作流程与助手协作](creation-workflow.md)。

### 共享资源分类与出图

共享资源页可按人物、场景、道具筛选，并显示各类数量。在分类中新增资源会预选对应类型。填写设定描述后，点击「生成设定图」即可直接出图，无需创建分集或制作方案，使用模型管理中配置的生图模型。

人物生成半身与全身图，场景生成空间全景与细节图，道具生成完整三分之四视角图。生成期间卡片显示任务状态，完成后图片保存为新版本，可查看历史版本或重新出图；任务记录也可查看生成结果。若生成期间编辑了资源，新编辑版本会继续保持当前版本。

### 项目概览

打开、新建或切换项目后，默认进入「项目概览」。项目名称直接作为标题，创作方向、视觉风格、画幅和统一创作规范展示在「基础信息」模块中。长内容在模块内滚动，点击模块右上角的「编辑」，使用与新建项目相同的弹窗修改，保存或取消后关闭弹窗。

「AI 完善基础信息」位于编辑弹窗内。助手按需读取当前输入和已有项目资料，可以生成名称、创作方向、视觉风格和统一规范的结果卡片；画幅由用户选择，检查并应用卡片后，再保存使其生效。基础信息是全项目共同的创作依据：分集、故事、分镜、设定及剪辑助手读取同一份规范，人物/场景/道具设定图和视频请求也会带入这些约定。修改规范后，进行中的方案会标记为待更新，已结束方案保留原结果。

下方以卡片展示全部分集，按集数倒序排列，首张卡片为「制作新一集」。已有成片的卡片使用真实视频第一帧作为封面，可直接播放；卡片同时显示当前制作状态和「继续制作／查看制作」入口。优先播放当前方案的有效成片；当前方案尚未出片时，仍展示该集其他方案最近完成的有效成片。过期成片不会作为当前结果列出。侧栏仅保留项目概览、共享资源和任务记录。从分集卡片的「继续制作／查看制作」进入该集工作台，工作台顶部显示项目与分集名称，并可直接返回项目概览。

修改创作约定会让进行中的方案待更新，原内容和媒体保留；已结束方案保留原有结果。配置有新的并发更新时，保存会提示重新载入，避免覆盖新数据。

### 小说的草稿与确认

小说编辑区只保留「保存草稿」与「确认并继续」两个动作，不再单独要求采用。保存草稿只保留当前修改，不改变已经确认的版本；没有未保存的修改时保存按钮禁用。确认会在同一次操作中保存需要保存的内容、设为当前确认稿，并进入视频方案。

操作栏状态跟随正在查看的稿件：未保存、草稿、已确认、待复核或历史稿。已确认且未修改时，主按钮改为进入视频方案。项目约定变化后重新确认会创建新版本，保留旧版本的内容和原始依据。切换稿件只改变查看对象，确认后才用于后续制作。

### 剧情状态与修订版本

制作中的「设定集」是剧情状态的主要入口。每项资源可以「修正当前状态」，也可以「新增剧情状态」：例如同一人物的校服与雨衣造型，同一场景的白天与火灾后状态。新增状态填写名称、标签、完整描述，并选择使用它的片段；新状态继承来源参考图，生成图片独立保存。只有所选片段切换，其他片段继续使用原状态。同一片段不能同时绑定同一资源的多个状态。

修正描述和重新出图属于同一状态的版本迭代；新增状态则保留独立的状态身份、来源版本、标签与图片。资源库中可以按状态查看历史版本，从资源库绑定时明确选择状态和版本。历史制作方案不会自动替换为最新版本。旧资源自动归入「初始状态」，无需迁移。

### 制作模块的统一标题工具栏

故事、视频方案、设定集、视频生成、合成导出与结束方案统一使用固定的标题行：模块名称后显示版本与当前状态，右侧放生成、保存、确认、导出等主操作。次要操作位于右侧「更多操作」，正文只负责内容编辑和预览。单个镜头、片段或设定条目的局部操作仍放在条目旁。切换阶段后工具栏随模块更新，已结束方案的编辑操作保持禁用。

### 查看生成时使用的 skill 与提示词

从模块点击「AI 生成」时，预置请求带有对应 skill 标签，例如 `@skill:story`。显式标签优先加载；没有标签时，助手可以自行加载匹配技能。当前表单和项目定位作为可按需读取的资料来源，助手通过工具查询，不直接拼进初始消息。环节与资源引用用于强调参考目标，不是读取资料的前置条件。

回复下的「本次 skill 与提示词」可展开查看本次实际发送的请求，包括 skill 文件来源、系统消息、上下文、对话和工具定义。请求预览不包含服务连接认证信息。自由聊天也可显式引用 skill；能否将结果应用到原表单，取决于技能匹配和表单快照是否仍有效。
