# 故障排查

[返回文档索引](README.md)

## 启动失败

### Node.js 或 SQLite 报错

运行 `node --version` 确认满足 Node.js 22.16+，并在项目根目录使用 `npm ci` 安装锁文件指定的依赖。应用使用 `node:sqlite`，不支持改用较旧 Node.js 版本。

部分 Node.js 版本会显示 SQLite 实验特性提示；单独的提示不代表启动失败，应查看后续错误。

### 端口已被占用

停止已有 Daydream 实例，或在 `.env.local` 设置其他 `PORT` 后重启。不要同时启动开发和生产实例使用同一工作区；同一数据库只允许一个后台执行器接管任务。

### 找不到生产构建

先运行 `npm run build`，成功后再运行 `npm start`。日常开发使用 `npm run dev`。

## 模型与服务

### 连接测试失败

在「模型管理 → 服务连接」检查 Key、服务地址、百炼地域及业务空间。自定义文本服务需要支持应用使用的 Chat Completions 接口；不支持模型列表接口时，连接测试会明确提示，必要时手动输入模型 ID。

测试使用当前输入的 Key，留空时使用已保存的密钥；测试连接不会保存配置，需要另外保存。

### 测试连接成功，但生成失败

连接测试只验证鉴权和模型列表查询。继续检查实际模型 ID、调用权限、余额、配额及服务返回的错误。目录可见不保证当前账号能调用该模型，图片或视频模型还需要应用已有相应适配。

### 修改环境变量没有生效

重启应用，确认命令在项目根目录运行。已保存的模型选择和连接配置优先于环境默认值；检查模型管理中的实际选择。运行中的模型任务会阻止配置修改，应等任务结束后再改。

## 助手与草稿

### 助手没有使用预期资料

从对应模块启动对话，使当前未保存表单作为可读取来源。助手应按需读取表单、项目规范和相关内容；可通过回复下的「本次 skill 与提示词」检查实际工具调用。若要强调特定环节、资源或技能，可用 `@` 引用。新会话不继承其他会话的历史消息，需要延续修改时应继续原会话。

### 结果卡片不能应用

检查原表单是否仍打开、是否在等待期间被修改、原方案是否已结束，以及结果技能是否与表单匹配。快照不一致时会阻止旧结果覆盖新编辑；可保留结果文本，再基于当前内容重新发起请求。

应用卡片后仍需保存或确认，具体以所在模块的操作为准。

## 任务与素材

### 重启后任务显示中断

在任务记录查看状态。带远端 ID 的视频任务可以继续查询原任务；整集任务可继续未完成部分。

如果提示提交结果不确定且没有远端 ID，先到供应商控制台核对任务和计费情况，再决定是否重新生成，避免重复提交。

### 素材显示待更新

上游故事、分镜、设定、模型或相关选项发生变化后，下游素材可能失效。检查待更新原因，按流程重新确认或生成。历史素材保留，但不一定能作为当前有效成片的输入。

### 移动工作区后看不到项目或无法解密配置

确认 `DATA_DIR`、`SQLITE_PATH` 指向原工作区，并恢复匹配的 `.encryption-key`。只更改路径不会自动搬迁原文件。完整步骤见[备份、恢复与迁移](data-management.md)。

## 视频与字幕导出

### FFmpeg 无法启动

确认 `npm ci` 已成功安装 `ffmpeg-static`。如果当前系统无法使用依赖提供的可执行文件，可安装适合本机的 FFmpeg，并用 `FFMPEG_BIN` 指定完整路径，确保该文件可执行。

### 字幕导出失败

自动识别和台词对齐会调用音频模型，检查对应服务的配置和权限。台词对齐无法完整保留台词时会失败，原成片仍保留；可核对实际语音与台词，或选择不添加字幕后重新导出。

## 提交问题

仍无法解决时，请按[贡献指南](../CONTRIBUTING.md#报告问题)提交 Node.js 版本、系统、复现步骤和脱敏错误。不要附上完整数据库、真实 Key、加密密钥或私人媒体。
